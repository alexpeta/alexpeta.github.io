# alexpeta.github.io

Hugo source for https://alexpeta.github.io/ (theme: harbor, vendored under `themes/harbor`).

- Posts live in `content/post/`; permalinks are `/:year/:month/:day/:contentbasename/`.
- Every push to `main` builds with Hugo 0.147.8 and deploys to GitHub Pages via Actions; pull requests build only.
- Local preview: `hugo server` with Hugo ≥ 0.146.
